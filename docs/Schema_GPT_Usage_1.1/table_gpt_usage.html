gpt_usage

One normalized record per model request: token counts, per-million rates, calculated costs, who asked, and which module asked. It drives usage and cost reports.

Group: Usage and cost reporting
Columns: 24 · Indexes: 5
Outgoing FKs: 0 · Referenced by: 0 tables
Database: krhomebase_gpt_usage_dev (binding GPT_USAGE_DB)
Canonical SQL: Schema_GPT_Usage_1.1.sql
Storage: Cloudflare D1 / SQLite
Developer notes. Costs are stored as REAL (floating point), so sums can carry rounding noise; reports should round. Rates are snapshotted per row, so later rate changes do not rewrite history. model_provider holds the connection type value in practice (the 2026-09-04 migration matches it to gpt_model_connection.connection_type). request_kind and response_status have no CHECK list.

Raw SQL (as stored in the database)
CREATE TABLE gpt_usage (
  id TEXT PRIMARY KEY,
  request_id TEXT NOT NULL UNIQUE,
  application_id TEXT NOT NULL DEFAULT 'krhomebase',
  model_provider TEXT NOT NULL,
  model_name TEXT NOT NULL,
  kr_gpt_connection_id TEXT,
  input_tokens INTEGER NOT NULL DEFAULT 0,
  cached_tokens INTEGER NOT NULL DEFAULT 0,
  output_tokens INTEGER NOT NULL DEFAULT 0,
  total_tokens INTEGER NOT NULL DEFAULT 0,
  input_rate_per_million REAL NOT NULL DEFAULT 0,
  cached_rate_per_million REAL NOT NULL DEFAULT 0,
  output_rate_per_million REAL NOT NULL DEFAULT 0,
  input_cost REAL NOT NULL DEFAULT 0,
  cached_cost REAL NOT NULL DEFAULT 0,
  output_cost REAL NOT NULL DEFAULT 0,
  total_cost REAL NOT NULL DEFAULT 0,
  requested_at TEXT NOT NULL,
  module_name TEXT NOT NULL,
  requested_by_user_id TEXT,
  requested_by_email TEXT,
  request_kind TEXT NOT NULL DEFAULT 'readiness',
  response_status TEXT NOT NULL DEFAULT 'success',
  created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
  CHECK (input_tokens >= 0), CHECK (cached_tokens >= 0), CHECK (output_tokens >= 0), CHECK (total_tokens >= 0),
  CHECK (input_rate_per_million >= 0), CHECK (cached_rate_per_million >= 0), CHECK (output_rate_per_million >= 0),
  CHECK (input_cost >= 0), CHECK (cached_cost >= 0), CHECK (output_cost >= 0), CHECK (total_cost >= 0)
);
