gpt_llm_credential

Credentials the Worker needs to call a provider model. One row per credential kind (api-key, account-id, project-id, gateway-auth-token) for each provider and model pair. Values are stored as an encrypted envelope.

Group: Credentials
Columns: 10 · Indexes: 1

Secret data. Never return, log, or commit the contents of this table.
Developer notes. Treat the whole table as secret. Never return key to a browser, log it, or copy it into source control. The composite primary key means credentials are per provider and model, not per connection. There is no foreign key from gpt_model_connection.credential_name to this table.

CREATE TABLE gpt_llm_credential (
  provider TEXT NOT NULL,
  llm_model TEXT NOT NULL,
  credential TEXT NOT NULL,
  "key" TEXT NOT NULL,
  is_key_encrypted INTEGER NOT NULL DEFAULT 1 CHECK (is_key_encrypted IN (0,1)),
  config1 TEXT,
  config2 TEXT,
  config3 TEXT,
  created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
  updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
  PRIMARY KEY (provider, llm_model, credential),
  CHECK (length(trim(provider)) > 0),
  CHECK (length(trim(llm_model)) > 0),
  CHECK (length(trim(credential)) > 0),
  CHECK (length(trim("key")) > 0)
);
