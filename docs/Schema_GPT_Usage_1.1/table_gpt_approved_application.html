gpt_approved_application

Application-level setting for the GPT Gateway: which application is approved to use it, its provider-neutral model settings, and whether it has received a successful model response yet. The prototype has one row, for krhomebase.

Group: Gateway configuration
Columns: 8 · Indexes: 0
Outgoing FKs: 0 · Referenced by: 0 tables
Database: krhomebase_gpt_usage_dev (binding GPT_USAGE_DB)
Canonical SQL: Schema_GPT_Usage_1.1.sql
Storage: Cloudflare D1 / SQLite
Developer notes. approved_api_key is named like a secret but is documented as a display-safe alias, never a credential value. Keep it that way; real keys belong only in gpt_llm_credential as an encrypted envelope. settings_json must stay free of provider secrets.
