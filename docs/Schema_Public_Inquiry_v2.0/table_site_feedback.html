site_feedback

Feedback submitted from the public website or from inside Homebase: bugs, content issues, design, accessibility, and workflow comments. It is stored in the same quarantined database and screened for bots like an inquiry.

Group: Site feedback
Columns: 34 · Indexes: 6
Outgoing FKs: 0 · Referenced by: 0 tables
Database: kr_public_inquiry_06_2026 (binding PUBLIC_INQUIRY_DB)
Canonical SQL: schema_public_inquiry_v2_0.sql
Storage: Cloudflare D1 / SQLite
Developer notes. Independent of public_inquiry (no foreign key). app_context separates public-site feedback from Homebase feedback. created_by_user_id is a Homebase user id with no enforced foreign key because the user table is in another database.

Raw SQL (as stored in the database)
CREATE TABLE site_feedback (
  id TEXT PRIMARY KEY,
  submitted_at TEXT NOT NULL,
  app_context TEXT NOT NULL CHECK (app_context IN ('public', 'homebase')),
  feedback_type TEXT NOT NULL CHECK (feedback_type IN ('general', 'bug', 'content', 'design', 'accessibility', 'workflow')),
  severity TEXT NOT NULL DEFAULT 'normal' CHECK (severity IN ('low', 'normal', 'high')),
  message TEXT NOT NULL,
  visitor_email TEXT,
  route_path TEXT,
  page_url TEXT,
  referrer_url TEXT,
  component_kr_id TEXT,
  viewport_width INTEGER,
  viewport_height INTEGER,
  user_agent TEXT,
  accept_language TEXT,
  ip_hash TEXT,
  ip_prefix TEXT,
  rate_limit_key_hash TEXT,
  turnstile_success INTEGER CHECK (turnstile_success IN (0, 1)),
  turnstile_action TEXT,
  turnstile_hostname TEXT,
  turnstile_error_codes TEXT,
  honeypot_triggered INTEGER NOT NULL DEFAULT 0 CHECK (honeypot_triggered IN (0, 1)),
  bot_decision TEXT NOT NULL,
  form_started_at TEXT,
  form_submitted_at TEXT,
  created_by_user_id TEXT,
  created_by_email TEXT,
  review_status TEXT NOT NULL DEFAULT 'new' CHECK (review_status IN ('new', 'reviewing', 'reviewed', 'closed', 'spam')),
  reviewed_at TEXT,
  reviewed_by_user_id TEXT,
  internal_notes TEXT,
  created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
  updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now'))
);
