public_inquiry_promotion_log

Audit record of an inquiry being promoted into the operational Homebase database as a contact and/or matter, with who promoted it and when.

Group: Review workflow
Columns: 7 · Indexes: 1
Outgoing FKs: 1 · Referenced by: 0 tables
Database: kr_public_inquiry_06_2026 (binding PUBLIC_INQUIRY_DB)
Canonical SQL: schema_public_inquiry_v2_0.sql
Storage: Cloudflare D1 / SQLite
Developer notes. The target ids point into the Homebase database, which is a different D1 database, so they cannot be foreign keys. public_inquiry also keeps promoted_to_contact_id and promoted_to_matter_id; the two copies can drift.

  id TEXT PRIMARY KEY,
  inquiry_id TEXT NOT NULL,
  promoted_to_contact_id TEXT,
