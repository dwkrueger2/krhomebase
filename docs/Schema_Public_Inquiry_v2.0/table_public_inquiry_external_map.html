public_inquiry_external_map

Optional crosswalk from an inquiry to a record in an outside system (for example a lead-management tool), with sync state. Added in v2.0 for future use.

Group: Review workflow
Columns: 10 · Indexes: 1
Outgoing FKs: 1 · Referenced by: 0 tables
Database: kr_public_inquiry_06_2026 (binding PUBLIC_INQUIRY_DB)
Canonical SQL: schema_public_inquiry_v2_0.sql
Storage: Cloudflare D1 / SQLite
Developer notes. UNIQUE (external_system, external_record_type, external_record_id) stops one outside record from mapping to two inquiries. There is no evidence in the schema that anything writes to it yet; confirm before relying on it.

Raw SQL (as stored in the database)
CREATE TABLE public_inquiry_external_map (
  id TEXT PRIMARY KEY,
  inquiry_id TEXT NOT NULL,
  external_system TEXT NOT NULL,
  external_record_type TEXT NOT NULL,
  external_record_id TEXT NOT NULL,
  external_url TEXT,
  sync_status TEXT NOT NULL DEFAULT 'mapped' CHECK (sync_status IN ('mapped','pending','synced','error','ignored')),
  last_sync_at TEXT,
  created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
  updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
  FOREIGN KEY (inquiry_id) REFERENCES public_inquiry(id) ON DELETE CASCADE,
  UNIQUE (external_system, external_record_type, external_record_id)
);
