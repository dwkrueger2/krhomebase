public_inquiry_intake_party

Names of related or opposing parties that the visitor listed, stored one per row so staff can run conflict triage before accepting the matter. Added in v2.0.

Raw SQL (as stored in the database)
CREATE TABLE public_inquiry_intake_party (
  id TEXT PRIMARY KEY,
  inquiry_id TEXT NOT NULL,
  party_name TEXT NOT NULL,
  party_role TEXT NOT NULL DEFAULT 'unknown',
  party_type TEXT NOT NULL DEFAULT 'unknown' CHECK (party_type IN ('person','organization','unknown')),
  contact_hint TEXT,
  conflict_note TEXT,
  created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
  FOREIGN KEY (inquiry_id) REFERENCES public_inquiry(id) ON DELETE CASCADE
);
