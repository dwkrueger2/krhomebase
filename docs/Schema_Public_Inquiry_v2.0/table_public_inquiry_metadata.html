public_inquiry_metadata

One row per inquiry with technical submission data: URLs, campaign tags and click IDs, hashed network identifiers, and browser headers. It supports attribution reporting and abuse review.

Group: Inquiry intake and review
Columns: 19 · Indexes: 2
Outgoing FKs: 1 · Referenced by: 0 tables
Database: kr_public_inquiry_06_2026 (binding PUBLIC_INQUIRY_DB)
Canonical SQL: schema_public_inquiry_v2_0.sql
Storage: Cloudflare D1 / SQLite
Developer notes. Primary key is inquiry_id, which makes this a strict one-to-one extension of public_inquiry. Raw IP addresses are not stored, only a hash and a prefix. Treat user_agent and campaign values as untrusted text.

  inquiry_id TEXT PRIMARY KEY,
  submitted_at TEXT NOT NULL,
