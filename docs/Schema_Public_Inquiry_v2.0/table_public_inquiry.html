public_inquiry

Quarantined record of one public consultation request submitted through the firm website. It holds what the visitor typed, their consents, the review status, and the lead-source fields. Nothing here is trusted: a human reviewer promotes an inquiry into Homebase contacts or matters.

Group: Inquiry intake and review

Storage: Cloudflare D1 / SQLite
Developer notes. This is the hub table: every other inquiry table points to it. promoted_to_contact_id and promoted_to_matter_id refer to rows in the separate Homebase database, so no foreign key can enforce them. urgency, matter_type and the v2.0 lead fields have no CHECK list. Columns were added in two steps (v1.2 and v2.0), so the live column order differs from the logical grouping.
