kr_session

Opaque web-session table. D1 stores token hashes and request metadata, never raw browser session tokens.

Common usage notes
  • Rows are retired rather than deleted: filter on revoked_at (and is_active where present) in normal list views.
  • Sensitive columns: session_token_hash, ip_hash, user_agent_hash. Never log them or return them to browsers.
