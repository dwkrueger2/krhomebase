employee_time_punch

Clock-in and clock-out punches on a time card with local date, timezone, source (button, auto-break resume, corrections, system), and void or supersede support for corrections.

Domain: Employees, Timekeeping, Payroll, and Teams
Columns: 14 · Indexes: 4
Outgoing FKs: 4 · Referenced by: 1 table
Source: live D1 (krhomebase_dev), read 2026-10-24
Canonical SQL: schema_d1_v8_0.sql
Storage: Cloudflare D1 / SQLite
New since Schema 7.0. This table was not part of the 7.0 documentation.
Developer notes. Correct by voiding or superseding, never by editing occurred_at. idempotency_key prevents duplicate punches from retried requests.

Common usage notes
  • Rows are retired rather than deleted: filter on voided_at (and is_active where present) in normal list views.
  • Controlled values are enforced by CHECK constraints on: punch_type, source. Update the constraint (table rebuild in SQLite/D1) when adding a value.
Raw SQL
CREATE TABLE employee_time_punch (
  id TEXT PRIMARY KEY,
  employee_id TEXT NOT NULL,
  time_card_id TEXT NOT NULL,
  punch_type TEXT NOT NULL CHECK (punch_type IN ('clock_in','clock_out')),
  occurred_at TEXT NOT NULL,
  local_date TEXT NOT NULL,
  timezone TEXT NOT NULL DEFAULT 'America/Chicago',
  source TEXT NOT NULL DEFAULT 'button' CHECK (source IN ('button','auto_break_resume','employee_correction','manager_correction','system')),
  correction_reason TEXT,
  supersedes_punch_id TEXT,
  voided_at TEXT,
  created_by_user_id TEXT NOT NULL,
  created_at TEXT NOT NULL DEFAULT (datetime('now')), idempotency_key TEXT,
  FOREIGN KEY (employee_id) REFERENCES employee(id),
  FOREIGN KEY (time_card_id) REFERENCES employee_time_card(id),
  FOREIGN KEY (supersedes_punch_id) REFERENCES employee_time_punch(id),
  FOREIGN KEY (created_by_user_id) REFERENCES user(id)
);
