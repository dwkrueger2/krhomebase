public_content

Articles and answers published to the public website: title, slug, status (draft, review, published, archived), sanitized HTML body, SEO fields, author, category, and publication timestamps. A trigger assigns the display sequence and display code on insert.

Common usage notes
  • Rows are retired rather than deleted: filter on archived_at (and is_active where present) in normal list views.
  • Controlled values are enforced by CHECK constraints on: content_type, status. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • JSON text columns (asset_manifest_json) are stored as TEXT; keep values that need filtering or reporting in typed columns.
  • Read by view: public_published_content.
  • Has trigger: public_content_sequence_after_insert.
Raw SQL
CREATE TABLE public_content (
    id                         TEXT PRIMARY KEY,
    content_type               TEXT NOT NULL CHECK (content_type IN ('article', 'answer')),
    title                      TEXT NOT NULL,
    slug                       TEXT NOT NULL,
    topic_slug                 TEXT,
    canonical_path             TEXT NOT NULL UNIQUE,
    status                     TEXT NOT NULL DEFAULT 'draft' CHECK (status IN ('draft', 'review', 'published', 'archived')),
    summary                    TEXT NOT NULL,
    thumbnail_r2_key           TEXT,
    thumbnail_public_url       TEXT,
    thumbnail_alt              TEXT NOT NULL DEFAULT '',
    body_format                TEXT NOT NULL DEFAULT 'sanitized_html' CHECK (body_format = 'sanitized_html'),
    sanitized_html             TEXT NOT NULL,
    source_upload_r2_key       TEXT,
    sanitized_snapshot_r2_key  TEXT,
    asset_manifest_json        TEXT,
    seo_title                  TEXT,
    seo_description            TEXT,
    author_id                  TEXT,
    author_display_name        TEXT,
    category                   TEXT,
    category_label             TEXT,
    pillar                     TEXT,
    reading_time_minutes       INTEGER CHECK (reading_time_minutes IS NULL OR reading_time_minutes >= 0),
    published_at               TEXT,
    unpublished_at             TEXT,
    created_at                 TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at                 TEXT,
    archived_at                TEXT,
    created_by_user_id         TEXT,
    updated_by_user_id         TEXT,
    last_publication_r2_key    TEXT, display_sequence INTEGER, display_code TEXT,
    CHECK (content_type = 'article' OR pillar IS NOT NULL),
    CHECK (content_type = 'article' OR topic_slug IS NOT NULL),
    CHECK (content_type = 'answer' OR category IS NOT NULL),
    CHECK (content_type = 'answer' OR canonical_path LIKE '/articles/%'),
    CHECK (content_type = 'article' OR canonical_path LIKE '/answers/%'),
    FOREIGN KEY (author_id) REFERENCES content_author(id),
    FOREIGN KEY (created_by_user_id) REFERENCES user(id),
    FOREIGN KEY (updated_by_user_id) REFERENCES user(id)
);
