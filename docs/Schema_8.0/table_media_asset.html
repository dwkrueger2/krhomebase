Common usage notes
  • Rows are retired rather than deleted: filter on deleted_at (and is_active where present) in normal list views.
  • Controlled values are enforced by CHECK constraints on: owner_type, purpose, visibility, status. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • owner_type + owner_id form a polymorphic owner reference; the database cannot enforce it with a foreign key, so the API must validate it.
Raw SQL
CREATE TABLE media_asset (
    id                   TEXT PRIMARY KEY,
    r2_bucket            TEXT NOT NULL DEFAULT 'krfirm-app-private',
    r2_key               TEXT NOT NULL UNIQUE,
    owner_type           TEXT NOT NULL CHECK (owner_type IN ('client','individual','user','matter','employee','entity','asset','system','temp')),
    owner_id             TEXT,
    purpose              TEXT NOT NULL CHECK (purpose IN (
                              'profile_image','card_image','matter_cover_image',
                              'document_original','document_version','employee_file',
                              'certification_document','review_document','temp_upload',
                              'system_export','thumbnail','preview','other')),
    content_type         TEXT NOT NULL,
    byte_size            INTEGER NOT NULL CHECK (byte_size >= 0),
    original_filename    TEXT,
    file_ext             TEXT,
    sha256               TEXT,
    width                INTEGER,
    height               INTEGER,
    visibility           TEXT NOT NULL DEFAULT 'private' CHECK (visibility IN ('private','public')),
    status               TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending','active','replaced','deleted','quarantined')),
    uploaded_by_user_id  TEXT,
    created_at           TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at           TEXT,
    deleted_at           TEXT,
    FOREIGN KEY (uploaded_by_user_id) REFERENCES user(id)
);
