Table definition · Billing, Ledger, Payments, and Trust

ledger_entry

The financial ledger: payments, credits, debits, write-offs, refunds, and adjustments applied to an invoice, matter, and client, each in a ledger bucket (for example receivable or trust) with a direction and amount.

Domain: Billing, Ledger, Payments, and Trust

Developer notes. Never delete; void (voided_at) so balances and the summary views stay auditable. Amounts are REAL.

Common usage notes
  • Rows are retired rather than deleted: filter on voided_at (and is_active where present) in normal list views.
  • Controlled values are enforced by CHECK constraints on: ledger_bucket, entry_type, entry_direction. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • Money columns (amount, amount_ex_tax, tax_amount, amount_inc_tax) are stored as REAL (floating point). Round at the application layer; consider integer cents for new money columns.
  • Read by views: invoice_ledger_summary, matter_ledger_bucket_summary.
Raw SQL
CREATE TABLE ledger_entry (
    id                      TEXT PRIMARY KEY,
    invoice_id              TEXT,
    matter_id               TEXT NOT NULL,
    client_id               TEXT,
    payment_id              TEXT,
    bank_deposit_id         TEXT,
    ledger_bucket           TEXT NOT NULL DEFAULT 'receivable'
                                 CHECK (ledger_bucket IN ('receivable','expense_paid','expense_recovery','trust','retainer_credit','wip','anticipated_expense','other')),
    entry_type              TEXT NOT NULL
                                 CHECK (entry_type IN ('charge','invoice','payment','credit','write_off','refund','adjustment','expense_paid','expense_recovery','retainer_credit','trust_deposit','trust_disbursement','opening_balance')),
    entry_direction         TEXT NOT NULL
                                 CHECK (entry_direction IN ('credit','debit')),
    payment_type_lookup_id  TEXT,
    amount                  REAL NOT NULL CHECK (amount >= 0),
    amount_ex_tax           REAL,
    tax_amount              REAL NOT NULL DEFAULT 0,
    amount_inc_tax          REAL,
    entry_date              TEXT NOT NULL,
    reference_number        TEXT,
    memo                    TEXT,
    notes                   TEXT,
    source_system           TEXT,
    source_record_id        TEXT,
    source_report_column    TEXT,
    received_by_user_id     TEXT,
    created_by_user_id      TEXT NOT NULL,
    created_at              TEXT NOT NULL DEFAULT (datetime('now')),
    voided_at               TEXT,
    voided_by_user_id       TEXT,
    void_reason             TEXT,
    FOREIGN KEY (invoice_id)             REFERENCES invoice(id),
    FOREIGN KEY (matter_id)              REFERENCES matter(id),
    FOREIGN KEY (client_id)              REFERENCES client(id),
    FOREIGN KEY (payment_id)             REFERENCES payment(id),
    FOREIGN KEY (bank_deposit_id)        REFERENCES bank_deposit(id),
    FOREIGN KEY (payment_type_lookup_id) REFERENCES lookup(id),
    FOREIGN KEY (received_by_user_id)    REFERENCES user(id),
    FOREIGN KEY (created_by_user_id)     REFERENCES user(id),
    FOREIGN KEY (voided_by_user_id)      REFERENCES user(id)
);
