Common usage notes
  • Controlled values are enforced by CHECK constraints on: entry_type. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • Money columns (balance_after_hours) are stored as REAL (floating point). Round at the application layer; consider integer cents for new money columns.
Raw SQL
CREATE TABLE employee_pto_ledger (
    id                       TEXT PRIMARY KEY,
    employee_id              TEXT NOT NULL,
    employee_time_event_id   TEXT,
    policy_id                TEXT,
    ledger_date              TEXT NOT NULL,
    entry_type               TEXT NOT NULL CHECK (entry_type IN ('accrual','usage','holiday','adjustment','carryover','cashout')),
    hours_delta              REAL NOT NULL,
    balance_after_hours      REAL,
    notes                    TEXT,
    created_by_user_id       TEXT NOT NULL,
    created_at               TEXT NOT NULL DEFAULT (datetime('now')),
    FOREIGN KEY (employee_id)            REFERENCES employee(id),
    FOREIGN KEY (employee_time_event_id) REFERENCES employee_time_event(id),
    FOREIGN KEY (policy_id)              REFERENCES hr_policy(id),
    FOREIGN KEY (created_by_user_id)     REFERENCES user(id)
);
