publication_event

Common usage notes
  • Controlled values are enforced by CHECK constraints on: content_type, event_type, status_after. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • JSON text columns (snapshot_json) are stored as TEXT; keep values that need filtering or reporting in typed columns.
Raw SQL
CREATE TABLE publication_event (
    id                         TEXT PRIMARY KEY,
    content_type               TEXT NOT NULL CHECK (content_type IN ('article', 'answer')),
    content_id                 TEXT NOT NULL,
    event_type                 TEXT NOT NULL CHECK (event_type IN ('save', 'publish', 'unpublish', 'archive', 'deleteArchived')),
    event_at                   TEXT NOT NULL,
    actor_user_id              TEXT,
    actor_role                 TEXT,
    status_after               TEXT NOT NULL CHECK (status_after IN ('draft', 'review', 'published', 'archived')),
    past_publication_r2_key    TEXT,
    snapshot_json              TEXT,
    created_at                 TEXT NOT NULL DEFAULT (datetime('now')),
    FOREIGN KEY (content_id) REFERENCES public_content(id) ON DELETE CASCADE,
    FOREIGN KEY (actor_user_id) REFERENCES user(id)
);
