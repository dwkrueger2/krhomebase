KR_DatabaseSchema/Notes, Communications, Tasks, and Reminders/task
Table definition · Notes, Communications, Tasks, and Reminders

task

An assignable work item with optional matter or client link, status, priority, assignee, assigner, lead user, due date, completion date, and billing-readiness fields (value, status, description).

Domain: Notes, Communications, Tasks, and Reminders

Storage: Cloudflare D1 / SQLite
Columns added since Schema 7.0: client_id, type_label, lead_user_id, workstream_activity_wsid, billing_value, billing_status, billing_description.
Developer notes. Billing fields describe whether the task is ready to be converted to billable time; they do not create invoices. billing_value is REAL.

Common usage notes
  • Controlled values are enforced by CHECK constraints on: status, priority, billing_status. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • Money columns (billing_value) are stored as REAL (floating point). Round at the application layer; consider integer cents for new money columns.
Raw SQL
CREATE TABLE task (
    id                       TEXT PRIMARY KEY,
    matter_id                TEXT,
    client_id                TEXT,
    project_identifier       TEXT,
    title                    TEXT NOT NULL,
    description              TEXT,
    type_label               TEXT,
    status                   TEXT NOT NULL DEFAULT 'open'
                               CHECK (status IN ('open','in_progress','waiting','completed','cancelled')),
    priority                 TEXT NOT NULL DEFAULT 'normal'
                               CHECK (priority IN ('low','normal','high','urgent')),
    assigned_to_user_id      TEXT,
    assigned_by_user_id      TEXT,
    lead_user_id             TEXT,
    workstream_activity_wsid TEXT,
    billing_value            REAL CHECK (billing_value IS NULL OR billing_value >= 0),
    billing_status           TEXT NOT NULL DEFAULT 'not_ready'
                               CHECK (billing_status IN ('not_ready','ready','converted','not_billable')),
    billing_description      TEXT,
    due_date                 TEXT,
    completed_at             TEXT,
    created_by_user_id       TEXT NOT NULL,
    created_at               TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at               TEXT,
    FOREIGN KEY (matter_id)                 REFERENCES matter(id),
    FOREIGN KEY (client_id)                 REFERENCES client(id),
    FOREIGN KEY (assigned_to_user_id)       REFERENCES user(id),
    FOREIGN KEY (assigned_by_user_id)       REFERENCES user(id),
    FOREIGN KEY (lead_user_id)              REFERENCES user(id),
    FOREIGN KEY (workstream_activity_wsid)  REFERENCES workstream_activity(wsid),
    FOREIGN KEY (created_by_user_id)        REFERENCES user(id)
);
