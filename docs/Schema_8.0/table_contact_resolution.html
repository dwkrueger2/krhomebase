Table definition · Identity and Parties

contact_resolution

An audit and idempotency record for contact clean-up operations (merge, copy-and-inactivate, inactivate). It remembers which individual or entity contact was resolved into which target so a repeated request does not repeat the operation.

Developer notes. UNIQUE (source_kind, source_contact_id) means each source contact can be resolved only once. Retried requests should reuse idempotency_key.

Raw SQL
CREATE TABLE "contact_resolution" (
    id                 TEXT PRIMARY KEY,
    source_kind        TEXT NOT NULL CHECK (source_kind IN ('individual','entity')),
    source_contact_id  TEXT NOT NULL,
    source_client_id   TEXT,
    target_kind        TEXT CHECK (target_kind IS NULL OR target_kind IN ('individual','entity')),
    target_contact_id  TEXT,
    target_client_id   TEXT,
    operation          TEXT NOT NULL CHECK (operation IN ('merge','copy_and_inactivate','inactivate')),
    reason             TEXT,
    actor_user_id      TEXT,
    actor_email        TEXT,
    request_id         TEXT,
    idempotency_key    TEXT UNIQUE,
    created_at         TEXT NOT NULL DEFAULT (datetime('now')),
    UNIQUE (source_kind, source_contact_id)
);
