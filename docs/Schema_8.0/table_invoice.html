KR_DatabaseSchema/Billing, Ledger, Payments, and Trust/invoice
Table definition · Billing, Ledger, Payments, and Trust

invoice

Billing invoice header for a matter and billed client: invoice number, dates, totals, status, and notes. ivid is the short public identifier used in client-facing payment links.

Domain: Billing, Ledger, Payments, and Trust

Columns added since Schema 7.0: ivid.
Developer notes. Totals are REAL. Payments are applied through payment_application and ledger_entry, not by editing the invoice.

Common usage notes
  • ivid is a short public identifier for this row; use it in screens, links, and references instead of the internal id.
  • Human-visible numbering column: invoice_number.
  • Controlled values are enforced by CHECK constraints on: status. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • Money columns (subtotal_amount, discount_amount, tax_amount, total_amount, amount_paid, balance_due) are stored as REAL (floating point). Round at the application layer; consider integer cents for new money columns.
  • Read by view: invoice_ledger_summary.
Raw SQL
CREATE TABLE invoice (
    id                   TEXT PRIMARY KEY,
    matter_id            TEXT NOT NULL,
    billing_profile_id   TEXT,
    billed_to_client_id  TEXT NOT NULL,
    invoice_number       TEXT NOT NULL UNIQUE,
    invoice_date         TEXT NOT NULL,
    period_start         TEXT,
    period_end           TEXT,
    due_date             TEXT,
    subtotal_amount      REAL NOT NULL DEFAULT 0 CHECK (subtotal_amount >= 0),
    discount_amount      REAL NOT NULL DEFAULT 0 CHECK (discount_amount >= 0),
    tax_amount           REAL NOT NULL DEFAULT 0 CHECK (tax_amount >= 0),
    total_amount         REAL NOT NULL DEFAULT 0 CHECK (total_amount >= 0),
    amount_paid          REAL NOT NULL DEFAULT 0 CHECK (amount_paid >= 0),
    balance_due          REAL NOT NULL DEFAULT 0,
    status               TEXT NOT NULL DEFAULT 'draft'
                             CHECK (status IN ('draft','sent','partially_paid','paid','overdue','void','written_off')),
    sent_at              TEXT,
    paid_at              TEXT,
    source_system        TEXT,
    source_invoice_number TEXT,
    notes                TEXT,
    created_at           TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at           TEXT, ivid TEXT
    CHECK (ivid IS NULL OR (length(ivid) = 7 AND ivid NOT GLOB '*[^A-Z0-9]*')),
    FOREIGN KEY (matter_id)           REFERENCES matter(id),
    FOREIGN KEY (billing_profile_id)  REFERENCES matter_billing_profile(id),
    FOREIGN KEY (billed_to_client_id) REFERENCES client(id)
);
