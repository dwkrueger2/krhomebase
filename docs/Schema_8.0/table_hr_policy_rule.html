Common usage notes
  • is_active hides retired rows from pickers while keeping history; filter on it in active lists.
  • Controlled values are enforced by CHECK constraints on: rule_type. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • JSON text columns (rule_json) are stored as TEXT; keep values that need filtering or reporting in typed columns.
  • Money columns (accrual_rate_per_hour, paid_hours) are stored as REAL (floating point). Round at the application layer; consider integer cents for new money columns.
Raw SQL
CREATE TABLE hr_policy_rule (
    id                       TEXT PRIMARY KEY,
    policy_id                TEXT NOT NULL,
    rule_type                TEXT NOT NULL CHECK (rule_type IN ('pto_accrual_tier','holiday','eligibility','other')),
    rule_label               TEXT NOT NULL,
    service_months_min       INTEGER CHECK (service_months_min IS NULL OR service_months_min >= 0),
    service_months_max       INTEGER CHECK (service_months_max IS NULL OR service_months_max >= 0),
    accrual_rate_per_hour    REAL CHECK (accrual_rate_per_hour IS NULL OR accrual_rate_per_hour >= 0),
    max_hours_per_year       REAL CHECK (max_hours_per_year IS NULL OR max_hours_per_year >= 0),
    paid_hours               REAL CHECK (paid_hours IS NULL OR paid_hours >= 0),
    rule_json                TEXT,
    sort_order               INTEGER NOT NULL DEFAULT 0,
    is_active                INTEGER NOT NULL DEFAULT 1 CHECK (is_active IN (0,1)),
    created_at               TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at               TEXT,
    FOREIGN KEY (policy_id) REFERENCES hr_policy(id)
);
