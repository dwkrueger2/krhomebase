Table definition · Clients and Matters

client

The client (or prospect) role attached to exactly one individual or one entity. It carries the client number, display name, status, and card-image metadata. Matters, invoices, payments, and assets hang off the client.

Developer notes. client_type (individual, entity, group) is enforced by a CHECK: an individual client has individual_id only, an entity client has entity_id only, and a group client has neither. Additional people on a joint client go in client_member. tax_identifier holds a full tax ID; treat it as highly sensitive and prefer tax_identifier_last4 for display.

  • Unique: client_number must be unique.
  • Foreign key: individual_id → individual(id) — no ON DELETE action declared (default NO ACTION)
  • Foreign key: entity_id → entity(id) — no ON DELETE action declared (default NO ACTION)

  • Check: prospect_status must be one of prospect, proposed, memo_sent, engagement_sent, intake_complete, engaged.
  • Check: status must be one of active, inactive.
  • Check: marketing_consent_status must be one of unknown, yes, no, not_asked, revoked.
  • Table check: (client_type = 'individual' AND individual_id IS NOT NULL AND entity_id IS NULL) OR (client_type = 'entity' AND entity_id IS NOT NULL AND individual_id IS NULL) OR (client_type = 'group' AND individual_id IS NULL AND entity_id IS NULL) — A client is exactly one of: an individual client (individual_id set, entity_id empty), an entity client (entity_id set, individual_id empty), or a group client (neither set). It must agree with client_type.

Common usage notes
  • Human-visible numbering column: client_number.
  • Controlled values are enforced by CHECK constraints on: client_type, prospect_status, status, marketing_consent_status. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • Sensitive columns: tax_identifier. Never log them or return them to browsers.
Raw SQL
CREATE TABLE client (
    id                         TEXT PRIMARY KEY,
    client_number              TEXT NOT NULL UNIQUE,
    client_type                TEXT NOT NULL CHECK (client_type IN ('individual','entity','group')),
    individual_id              TEXT,
    entity_id                  TEXT,
    display_name               TEXT NOT NULL,
    short_name                 TEXT,
    card_image_media_id        TEXT,
    prospect_status            TEXT NOT NULL DEFAULT 'prospect'
                                   CHECK (prospect_status IN (
                                       'prospect','proposed','memo_sent',
                                       'engagement_sent','intake_complete','engaged')),
    intake_date                TEXT,
    status                     TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('active','inactive')),
    marketing_consent_status   TEXT NOT NULL DEFAULT 'unknown'
                                   CHECK (marketing_consent_status IN ('unknown','yes','no','not_asked','revoked')),
    marketing_consent_at       TEXT,
    tax_identifier_last4       TEXT,
    tax_identifier  TEXT,
    source_system              TEXT,
    source_client_number       TEXT,
    source_card_name           TEXT,
    source_short_name          TEXT,
    import_batch_id            TEXT,
    created_at                 TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at                 TEXT,
    CHECK (
        (client_type = 'individual' AND individual_id IS NOT NULL AND entity_id IS NULL)
        OR
        (client_type = 'entity' AND entity_id IS NOT NULL AND individual_id IS NULL)
        OR
        (client_type = 'group' AND individual_id IS NULL AND entity_id IS NULL)
    ),
    FOREIGN KEY (individual_id)       REFERENCES individual(id),
    FOREIGN KEY (entity_id)           REFERENCES entity(id),
    FOREIGN KEY (card_image_media_id) REFERENCES media_asset(id),
    FOREIGN KEY (import_batch_id)     REFERENCES import_batch(id)
);
