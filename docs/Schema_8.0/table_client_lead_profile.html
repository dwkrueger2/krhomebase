client_lead_profile

The intake profile for an individual: pipeline stage, source, referral details, campaign, contact and qualification timestamps, conversion or loss details, and the assigned user. One profile per individual.

Domain: Intake and Lead Management

Developer notes. Since the 7.0 rehome this table is keyed by individual_id (previously client_id). Older rows that could not be matched were archived to client_lead_profile_legacy_orphan.
