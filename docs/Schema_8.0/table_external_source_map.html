Common usage notes
  • Controlled values are enforced by CHECK constraints on: mapping_status. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • JSON text columns (source_json) are stored as TEXT; keep values that need filtering or reporting in typed columns.
Raw SQL
CREATE TABLE external_source_map (
    id                  TEXT PRIMARY KEY,
    import_batch_id     TEXT,
    source_system       TEXT NOT NULL DEFAULT 'LEAP',
    source_table        TEXT,
    source_file_name    TEXT,
    source_row_number   INTEGER,
    source_record_id    TEXT,
    source_key          TEXT,
    target_table        TEXT NOT NULL,
    target_id           TEXT NOT NULL,
    target_field        TEXT,
    source_json         TEXT,
    mapping_status      TEXT NOT NULL DEFAULT 'mapped'
                            CHECK (mapping_status IN ('staged','mapped','ignored','needs_review','failed')),
    notes               TEXT,
    created_at          TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at          TEXT,
    FOREIGN KEY (import_batch_id) REFERENCES import_batch(id)
);
