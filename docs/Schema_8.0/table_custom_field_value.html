Common usage notes
  • Controlled values are enforced by CHECK constraints on: owner_type. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • owner_type + owner_id form a polymorphic owner reference; the database cannot enforce it with a foreign key, so the API must validate it.
  • JSON text columns (value_json) are stored as TEXT; keep values that need filtering or reporting in typed columns.
  • Money columns (value_number) are stored as REAL (floating point). Round at the application layer; consider integer cents for new money columns.
Raw SQL
CREATE TABLE custom_field_value (
  id TEXT PRIMARY KEY,
  definition_id TEXT NOT NULL,
  owner_type TEXT NOT NULL CHECK (owner_type IN ('client','matter','individual','entity','asset','document','invoice','lead')),
  owner_id TEXT NOT NULL,
  value_text TEXT,
  value_number REAL,
  value_date TEXT,
  value_json TEXT,
  created_by_user_id TEXT,
  updated_by_user_id TEXT,
  created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
  updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
  FOREIGN KEY (definition_id) REFERENCES custom_field_definition(id) ON DELETE CASCADE,
  FOREIGN KEY (created_by_user_id) REFERENCES user(id) ON DELETE SET NULL,
  FOREIGN KEY (updated_by_user_id) REFERENCES user(id) ON DELETE SET NULL,
  UNIQUE (definition_id, owner_type, owner_id)
);
