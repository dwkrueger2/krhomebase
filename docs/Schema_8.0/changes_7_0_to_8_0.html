Notes
  • client_lead_profile was rehomed from client_id to individual_id; unmatched legacy rows were archived into client_lead_profile_legacy_orphan. The client_id column no longer exists on the live table.
  • Short public identifiers were added: icid (individual), ecid (entity), ivid (invoice), bcid (time entry), lcid (lead), wsid (workstream activity), prid (payment request), ppid (payment provider).
  • Teams, multi-role assignment, scope-aware permissions, time cards and punches, the lead table, the workstream feed, online payment requests, payment providers, and a maintenance gate are the main functional additions.
  • There is no 7.0-to-8.0 migration SQL: Schema 8.0 documents the database as it already exists. Use schema_d1_v8_0.sql to create a fresh database that matches it.
