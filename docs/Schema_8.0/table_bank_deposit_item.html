bank_deposit_item

One line on a deposit slip (online payment, cash, check, ACH, wire, other) with matter, receipt number, drawer, masked account data, and amount.

Common usage notes
  • Controlled values are enforced by CHECK constraints on: item_type. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • Sensitive columns: routing_last4, routing_number, account_number. Never log them or return them to browsers.
  • Money columns (amount) are stored as REAL (floating point). Round at the application layer; consider integer cents for new money columns.
Raw SQL
CREATE TABLE bank_deposit_item (
    id                     TEXT PRIMARY KEY,
    bank_deposit_id        TEXT NOT NULL,
    payment_id             TEXT,
    ledger_entry_id        TEXT,
    item_type              TEXT NOT NULL DEFAULT 'online_payment'
                                CHECK (item_type IN ('online_payment','cash','check','ach','wire','other')),
    source_receipt_number  TEXT,
    matter_id              TEXT,
    matter_number_text     TEXT,
    drawer_name            TEXT,
    routing_last4          TEXT,
    routing_number     TEXT,
    account_last4          TEXT,
    account_number     TEXT,
    amount                 REAL NOT NULL CHECK (amount >= 0),
    notes                  TEXT,
    created_at             TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at             TEXT,
    FOREIGN KEY (bank_deposit_id) REFERENCES bank_deposit(id),
    FOREIGN KEY (payment_id)      REFERENCES payment(id),
    FOREIGN KEY (ledger_entry_id) REFERENCES ledger_entry(id),
    FOREIGN KEY (matter_id)       REFERENCES matter(id)
);
