billing_activity_code

Dictionary of billing and time-entry activity codes, with descriptions, default billing modes, and optional default rates. Seeded from an external practice-management system.

Common usage notes
  • is_active hides retired rows from pickers while keeping history; filter on it in active lists.
  • Money columns (default_rate) are stored as REAL (floating point). Round at the application layer; consider integer cents for new money columns.
Raw SQL
CREATE TABLE billing_activity_code (
    id                    TEXT PRIMARY KEY,
    code                  TEXT NOT NULL UNIQUE,
    label                 TEXT NOT NULL,
    description           TEXT,
    jurisdiction_state    TEXT,
    default_billing_mode  TEXT CHECK (default_billing_mode IS NULL OR default_billing_mode IN ('hourly_billable','flat_fee_tracked','flat_fee_billable','non_billable','no_charge','pro_bono','internal')),
    default_rate          REAL CHECK (default_rate IS NULL OR default_rate >= 0),
    is_active             INTEGER NOT NULL DEFAULT 1 CHECK (is_active IN (0,1)),
    source_system         TEXT,
    created_at            TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at            TEXT
);
