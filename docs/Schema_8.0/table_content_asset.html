content_asset

Image or file used by a piece of public content, with its R2 key, public URL, MIME type, size, dimensions, usage (body, thumbnail, both), alt text, and hash.

Raw SQL
CREATE TABLE content_asset (
    id                     TEXT PRIMARY KEY,
    content_id             TEXT NOT NULL,
    original_relative_path TEXT NOT NULL,
    r2_key                 TEXT NOT NULL UNIQUE,
    public_url             TEXT NOT NULL,
    mime_type              TEXT NOT NULL,
    file_size              INTEGER NOT NULL CHECK (file_size >= 0),
    width                  INTEGER,
    height                 INTEGER,
    usage                  TEXT NOT NULL CHECK (usage IN ('body', 'thumbnail', 'both')),
    alt_text               TEXT NOT NULL DEFAULT '',
    sha256                 TEXT,
    created_at             TEXT NOT NULL DEFAULT (datetime('now')),
    FOREIGN KEY (content_id) REFERENCES public_content(id) ON DELETE CASCADE
);
