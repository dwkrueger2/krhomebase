Table definition · Notes, Communications, Tasks, and Reminders

workstream_activity

The workstream feed: dated, internal-only activity entries (phone calls, emails, notes, tasks, received and sent files, work in progress) recorded against exactly one client or one lead, optionally tied to a matter, document, and task. Each entry has a 7-character public id (wsid).

Common usage notes
  • wsid is a short public identifier for this row; use it in screens, links, and references instead of the internal id.
  • Controlled values are enforced by CHECK constraints on: subgroup, note_format. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • JSON text columns (next_steps_json) are stored as TEXT; keep values that need filtering or reporting in typed columns.
Raw SQL
CREATE TABLE "workstream_activity" (
    id                   TEXT NOT NULL PRIMARY KEY,
    wsid                 TEXT NOT NULL UNIQUE
                           CHECK (length(wsid) = 7 AND wsid NOT GLOB '*[^A-Z0-9]*'),
    client_id            TEXT,
    lead_id              TEXT,
    matter_id            TEXT,
    subgroup             TEXT NOT NULL
                           CHECK (subgroup IN ('PhoneCalls','Emails','Notes','Tasks','ReceivedFiles','SentFiles','WIP')),
    activity_at          TEXT NOT NULL DEFAULT (datetime('now')),
    subject              TEXT NOT NULL,
    note_body            TEXT,
    note_format          TEXT NOT NULL DEFAULT 'html'
                           CHECK (note_format IN ('plain','markdown','html')),
    next_steps_json      TEXT,
    document_record_id   TEXT,
    document_url         TEXT,
    document_label       TEXT,
    task_id              TEXT,
    assignee_user_id     TEXT,
    assignee_contact_id  TEXT,
    assignee_label       TEXT,
    visibility           TEXT NOT NULL DEFAULT 'internal'
                           CHECK (visibility = 'internal'),
    performed_by_user_id TEXT,
    created_at           TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at           TEXT,
    FOREIGN KEY (client_id)            REFERENCES client(id),
    FOREIGN KEY (lead_id)              REFERENCES lead(id),
    FOREIGN KEY (matter_id)            REFERENCES matter(id),
    FOREIGN KEY (document_record_id)   REFERENCES document_record(id),
    FOREIGN KEY (assignee_user_id)     REFERENCES user(id),
    FOREIGN KEY (performed_by_user_id) REFERENCES user(id),
    CHECK ((client_id IS NOT NULL AND lead_id IS NULL) OR (client_id IS NULL AND lead_id IS NOT NULL))
);
