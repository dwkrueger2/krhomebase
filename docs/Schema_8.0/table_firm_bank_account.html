firm_bank_account

Firm bank account metadata (operating, trust, merchant, other). Routing and account numbers are held in restricted fields with last-four display helpers.

Common usage notes
  • is_active hides retired rows from pickers while keeping history; filter on it in active lists.
  • Controlled values are enforced by CHECK constraints on: account_type. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • Sensitive columns: routing_last4, routing_number, account_number. Never log them or return them to browsers.
Raw SQL
CREATE TABLE firm_bank_account (
    id                         TEXT PRIMARY KEY,
    account_name               TEXT NOT NULL,
    account_type               TEXT NOT NULL DEFAULT 'operating'
                                   CHECK (account_type IN ('operating','trust','savings','merchant','other')),
    bank_name                  TEXT,
    routing_last4              TEXT,
    routing_number         TEXT,
    account_last4              TEXT,
    account_number         TEXT,
    external_account_name      TEXT,
    is_active                  INTEGER NOT NULL DEFAULT 1 CHECK (is_active IN (0,1)),
    notes                      TEXT,
    created_at                 TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at                 TEXT
);
