KR_DatabaseSchema/Contacts, Addresses, and Communication Methods/address
Table definition · Contacts, Addresses, and Communication Methods

address

A reusable physical or mailing address. Individuals and entities link to it through address-history tables so old addresses are preserved when someone moves.

Domain: Contacts, Addresses, and Communication Methods
Columns: 21 · Indexes: 3
Outgoing FKs: 0 · Referenced by: 2 tables

Canonical SQL: schema_d1_v8_0.sql
Storage: Cloudflare D1 / SQLite
Developer notes. Do not edit an address in place to represent a move; add a new address and a new assignment row instead.

Raw SQL
CREATE TABLE address (
    id                  TEXT PRIMARY KEY,
    building_name       TEXT,
    street_level        TEXT,
    street_number       TEXT,
    street_name         TEXT,
    street1             TEXT,
    street2             TEXT,
    city                TEXT,
    state               TEXT,
    postal_code         TEXT,
    country             TEXT NOT NULL DEFAULT 'US',
    county              TEXT,
    po_box_type         TEXT,
    po_box_number       TEXT,
    po_box_instructions TEXT,
    address_quality     TEXT NOT NULL DEFAULT 'imported'
                              CHECK (address_quality IN ('verified','imported','partial','unknown')),
    source_system       TEXT,
    source_raw_text     TEXT,
    notes               TEXT,
    created_at          TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at          TEXT
);
