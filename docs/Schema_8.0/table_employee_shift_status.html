Table definition · Employees, Timekeeping, Payroll, and Teams

employee_shift_status

Optional short status note and location associated with one official clock-in shift. The API clears both values when that shift is clocked out.

Columns: 8 · Indexes: 1
Outgoing FKs: 3
Added by: Migration 062
Storage: Cloudflare D1 / SQLite

Storage boundary. This table is not the attendance record. Clock state comes from employee_time_punch; this table holds only the optional current-shift note and location.

Fields
FieldTypeConstraintsHuman purpose / technical specification

employee_idTEXTFK, requiredEmployee whose shift status is stored; references employee.id.

updated_atTEXTRequiredWhen the status row was last changed or cleared.
Constraints and indexes
  • Primary key: id.
  • Unique: one status row per clock-in punch.
  • Foreign keys: employee_id → employee(id); clock_in_punch_id → employee_time_punch(id); updated_by_user_id → user(id).
  • Checks: status_note is at most 160 characters; location is at most 100 characters.
  • Index: idx_employee_shift_status_employee on employee_id, updated_at.
Raw SQL
CREATE TABLE employee_shift_status (
  id TEXT PRIMARY KEY,
  employee_id TEXT NOT NULL,
  clock_in_punch_id TEXT NOT NULL UNIQUE,
  status_note TEXT CHECK (status_note IS NULL OR length(status_note) <= 160),
  location TEXT CHECK (location IS NULL OR length(location) <= 100),
  updated_by_user_id TEXT NOT NULL,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  FOREIGN KEY (employee_id) REFERENCES employee(id),
  FOREIGN KEY (clock_in_punch_id) REFERENCES employee_time_punch(id),
  FOREIGN KEY (updated_by_user_id) REFERENCES user(id)
);
CREATE INDEX idx_employee_shift_status_employee ON employee_shift_status(employee_id, updated_at);
