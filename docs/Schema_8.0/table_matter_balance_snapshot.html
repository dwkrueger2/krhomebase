matter_balance_snapshot

Point-in-time matter financial summary imported from an external practice-management system: work in progress, receivables, trust balance, retainer/credits, expense buckets, staff, billing category, and reporting group.

Domain: Billing, Ledger, Payments, and Trust
Columns: 36 · Indexes: 3
Outgoing FKs: 2 · Referenced by: 0 tables
Source: live D1 (krhomebase_dev), read 2026-10-24
Canonical SQL: schema_d1_v8_0.sql
Storage: Cloudflare D1 / SQLite
Developer notes. Imported snapshot, not a live balance. Live balances come from ledger_entry and the summary views.
