KR_DatabaseSchema/Identity and Parties/individual
Table definition · Identity and Parties

individual

The master record for a real human being. Names, date of birth, identity notes, contact methods, addresses, relationships, client roles, login accounts, and employee files all attach to this one identity row, so a person is never duplicated across roles. Used by nearly every module.

Common usage notes

Raw SQL
CREATE TABLE individual (
    id             TEXT PRIMARY KEY,
    title_prefix   TEXT,
    first_name     TEXT NOT NULL,
    middle_name    TEXT,
    last_name      TEXT NOT NULL,
    suffix         TEXT,
    preferred_name TEXT,
    dob            TEXT,
    ssn            TEXT,
    ssn_last4      TEXT,
    is_minor       INTEGER NOT NULL DEFAULT 0 CHECK (is_minor IN (0,1)),
    notes          TEXT,
    created_at     TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at     TEXT
, is_attorney INTEGER NOT NULL DEFAULT 0 CHECK (is_attorney IN (0,1)), icid TEXT);
