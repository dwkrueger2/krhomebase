lookup

Controlled vocabulary values (category, value, label) used by statuses, workflow labels, priorities, categories, relationship types, and other reusable UI lists.

Raw SQL
CREATE TABLE lookup (
    id            TEXT PRIMARY KEY,
    category      TEXT NOT NULL,
    value         TEXT NOT NULL,
    label         TEXT NOT NULL,
    description   TEXT,
    sort_order    INTEGER NOT NULL DEFAULT 0,
    is_active     INTEGER NOT NULL DEFAULT 1 CHECK (is_active IN (0,1)),
    created_at    TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at    TEXT,
    UNIQUE (category, value)
);
