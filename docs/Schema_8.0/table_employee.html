Table definition · Employees, Timekeeping, Payroll, and Teams

employee

Employee/HR file attached to a user account. Personal identity comes from the linked user and individual; HR, payroll, emergency-contact, and employment details live here. is_1099_vendor marks contractors who are not payroll employees.

Common usage notes
  • Human-visible numbering column: employee_number.
  • Controlled values are enforced by CHECK constraints on: employment_status, login_status, pay_type. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • Sensitive columns: ssn_last4, ssn. Never log them or return them to browsers.
  • Money columns (pto_balance_hours, current_pay_rate) are stored as REAL (floating point). Round at the application layer; consider integer cents for new money columns.
Raw SQL
CREATE TABLE employee (
    id                       TEXT PRIMARY KEY,
    user_id                  TEXT NOT NULL UNIQUE,
    employee_number          TEXT UNIQUE,
    staff_code               TEXT UNIQUE,
    employment_status        TEXT NOT NULL DEFAULT 'active'
                                  CHECK (employment_status IN ('active','on_leave','terminated','contractor','inactive')),
    job_title                TEXT,
    department               TEXT,
    qualification            TEXT,
    login_status             TEXT NOT NULL DEFAULT 'enabled'
                                  CHECK (login_status IN ('enabled','disabled','locked','pending','unknown')),
    show_in_staff_list       INTEGER NOT NULL DEFAULT 1 CHECK (show_in_staff_list IN (0,1)),
    hire_date                TEXT,
    termination_date         TEXT,
    review_cycle_anchor_date TEXT,
    last_review_date         TEXT,
    last_review_notes        TEXT,
    next_review_date         TEXT,
    employee_folder_url      TEXT,
    private_hr_folder_url    TEXT,
    pto_policy_id            TEXT,
    pto_balance_hours        REAL NOT NULL DEFAULT 0,
    pay_type                 TEXT NOT NULL DEFAULT 'hourly' CHECK (pay_type IN ('hourly','salary','contract')),
    current_pay_rate         REAL CHECK (current_pay_rate IS NULL OR current_pay_rate >= 0),
    pay_rate_effective_date  TEXT,
    staff_created_date       TEXT,
    user_created_date        TEXT,
    employee_image_media_id  TEXT,
    ssn_last4                TEXT,
    ssn           TEXT,
    emergency_contact_name   TEXT,
    emergency_contact_phone  TEXT,
    notes                    TEXT,
    created_at               TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at               TEXT, is_1099_vendor INTEGER NOT NULL DEFAULT 0 CHECK (is_1099_vendor IN (0,1)),
    FOREIGN KEY (user_id)                 REFERENCES user(id),
    FOREIGN KEY (employee_image_media_id) REFERENCES media_asset(id),
    FOREIGN KEY (pto_policy_id)           REFERENCES hr_policy(id)
);
