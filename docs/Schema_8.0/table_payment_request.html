Table definition · Billing, Ledger, Payments, and Trust

payment_request

A client-facing online payment link for an invoice. Stores only a hash of the one-time link token, the expiry, view and attempt counters, the payment intent, and, once paid, the resulting payment record. link_source records whether the link was emailed or printed.

Common usage notes
  • prid is a short public identifier for this row; use it in screens, links, and references instead of the internal id.
  • Human-visible numbering columns: invoice_number, client_number, payment_number.
  • Rows are retired rather than deleted: filter on revoked_at (and is_active where present) in normal list views.
  • Controlled values are enforced by CHECK constraints on: environment, status, link_source. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • Sensitive columns: token_hash, token_hint. Never log them or return them to browsers.
  • Money columns (paid_amount) are stored as REAL (floating point). Round at the application layer; consider integer cents for new money columns.
Raw SQL
CREATE TABLE payment_request (
    id                          TEXT PRIMARY KEY,
    prid                        TEXT NOT NULL UNIQUE CHECK (length(prid) = 7),
    invoice_id                  TEXT NOT NULL,
    invoice_ivid                TEXT NOT NULL,
    invoice_number              TEXT NOT NULL,
    client_id                   TEXT NOT NULL,
    client_number               TEXT NOT NULL,
    environment                 TEXT NOT NULL CHECK (environment IN ('sandbox', 'live')),
    token_hash                  TEXT NOT NULL UNIQUE CHECK (length(token_hash) = 64),
    token_hint                  TEXT NOT NULL,
    status                      TEXT NOT NULL DEFAULT 'open' CHECK (status IN ('open', 'paid', 'posted', 'expired', 'revoked')),
    expires_at                  TEXT NOT NULL,
    sent_document_number        TEXT,
    first_viewed_at             TEXT,
    last_viewed_at              TEXT,
    view_count                  INTEGER NOT NULL DEFAULT 0,
    intent_created_at           TEXT,
    intent_attempts             INTEGER NOT NULL DEFAULT 0,
    stripe_payment_intent_id    TEXT UNIQUE,
    stripe_event_id             TEXT,
    payer_email                 TEXT,
    paid_amount                 REAL,
    paid_at                     TEXT,
    payment_id                  TEXT UNIQUE,
    payment_number              TEXT,
    posted_at                   TEXT,
    post_error                  TEXT,
    revoked_at                  TEXT,
    revoked_by_user_id          TEXT,
    revoke_reason               TEXT,
    created_by_user_id          TEXT,
    created_at                  TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
    updated_at                  TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')), link_source TEXT NOT NULL DEFAULT 'email' CHECK (link_source IN ('email', 'print')),
    FOREIGN KEY (invoice_id)         REFERENCES invoice(id) ON DELETE RESTRICT,
    FOREIGN KEY (client_id)          REFERENCES client(id)  ON DELETE RESTRICT,
    FOREIGN KEY (payment_id)         REFERENCES payment(id) ON DELETE SET NULL,
    FOREIGN KEY (revoked_by_user_id) REFERENCES user(id)    ON DELETE SET NULL,
    FOREIGN KEY (created_by_user_id) REFERENCES user(id)    ON DELETE SET NULL
);
