employee_time_event

Employee timekeeping and pay-reporting event: work period, hours, pay period, approval, and creator. Optionally linked to a time card.

Common usage notes
  • Controlled values are enforced by CHECK constraints on: time_type, status. Update the constraint (table rebuild in SQLite/D1) when adding a value.
  • Money columns (pay_rate, pto_accrual_rate) are stored as REAL (floating point). Round at the application layer; consider integer cents for new money columns.
Raw SQL
CREATE TABLE employee_time_event (
    id                         TEXT PRIMARY KEY,
    employee_id                TEXT NOT NULL,
    pay_period_id              TEXT,
    work_date                  TEXT NOT NULL,
    start_at                   TEXT,
    end_at                     TEXT,
    break_minutes              INTEGER NOT NULL DEFAULT 0 CHECK (break_minutes >= 0),
    hours                      REAL NOT NULL CHECK (hours >= 0),
    pay_rate                   REAL CHECK (pay_rate IS NULL OR pay_rate >= 0),
    time_type                  TEXT NOT NULL DEFAULT 'regular'
                                    CHECK (time_type IN ('regular','overtime','pto','holiday','sick','unpaid','other')),
    status                     TEXT NOT NULL DEFAULT 'draft'
                                    CHECK (status IN ('draft','submitted','approved','rejected','paid')),
    pay_period_start           TEXT,
    pay_period_end             TEXT,
    is_pto_accrual_eligible    INTEGER NOT NULL DEFAULT 1 CHECK (is_pto_accrual_eligible IN (0,1)),
    pto_accrual_rate           REAL CHECK (pto_accrual_rate IS NULL OR pto_accrual_rate >= 0),
    pto_hours_accrued          REAL NOT NULL DEFAULT 0,
    submitted_at               TEXT,
    approved_by_user_id        TEXT,
    approved_at                TEXT,
    rejected_by_user_id        TEXT,
    rejected_at                TEXT,
    rejection_reason           TEXT,
    payroll_exported_at        TEXT,
    notes                      TEXT,
    created_by_user_id         TEXT NOT NULL,
    created_at                 TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at                 TEXT, time_card_id TEXT,
    FOREIGN KEY (employee_id)         REFERENCES employee(id),
    FOREIGN KEY (pay_period_id)       REFERENCES pay_period(id),
    FOREIGN KEY (approved_by_user_id) REFERENCES user(id),
    FOREIGN KEY (rejected_by_user_id) REFERENCES user(id),
    FOREIGN KEY (created_by_user_id)  REFERENCES user(id)
);
